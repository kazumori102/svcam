# svcam

Windows 用の DirectShow フィルタに基づくシンプルな仮想カメラコード。  
ただし Internet Explorer や Metro アプリでは動作しません。  
(これらは DirectShow ではなく Media Foundation を使用しているため)

A simple virtual camera code based on DirectShow filters for Windows.  
It won't work with Internet Explorer or Metro apps though.  
(which uses Media Foundation, not DirectShow)

P.S.
令和の時代に興味関心等のプラスな経緯でもなくDirectShowを取り扱わされている哀れな同志のために、  
1つでも多くのサンプルをフォークして残していきます。
